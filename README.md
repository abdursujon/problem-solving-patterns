## How to Approach a Problem in an Interview (6 Steps)
1. Read the question two times, including the example case, and ask clarifying questions to the interviewer.

2. Recognise the pattern and talk to the interviewer about different approaches and write down sudo code when needed and clarify why you think a certain data structure works for the given problem.

3. Approximate the complexity and write down the guess.

4. Code the solution and make sure the code is readable. 

5. Restate the complexity, and if the complexity changed, explain why.

6. Test the code with sample examples.
